UPLOAD NAAR GITHUB
1. Open jouw repository 'dealflow-ma-app'.
2. Klik 'uploading an existing file' of Add file > Upload files.
3. Upload ALLE vijf bestanden hierboven rechtstreeks naar de hoofdmap van de repository.
   Zorg dat index.html dus NIET in een extra submap staat.
4. Klik Commit changes.
5. Ga naar Settings > Pages.
6. Bij Source: kies 'Deploy from a branch'.
7. Branch: main.
8. Folder: / (root).
9. Klik Save.

IPHONE
1. Wacht tot GitHub Pages de site heeft gepubliceerd.
2. Open de Pages-link in Safari op je iPhone.
3. Tik op Delen.
4. Kies 'Zet op beginscherm'.
5. Open DealFlow vanaf je beginscherm.

Let op:
Deze versie bewaart gegevens lokaal op het apparaat. Realtime teamsynchronisatie
vereist een gedeelde database/backend, bijvoorbeeld Supabase.
